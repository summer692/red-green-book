# 红绿书出图器

把学校的零散信息，快速做成**固定风格的 3:4 图文卡片**，发小红书 / 小绿书（微信）。
选平台 → 填（或让 Claude 整理）内容 → 一键导出图片，省掉每次在创客贴里手动排版的时间。

## 怎么用

1. 打开页面，顶部选 **小红书** 或 **小绿书**（整体风格随之切换）。
2. 想偷懒就用「**用 Claude 整理零散信息**」：
   - 把官网那段原文粘进①，点「**让 Claude 整理 →**」会打开 Claude App 并带上提示词；
     打不开就点「**复制提示词**」，自己去 Claude 里粘贴。
   - 把 Claude 返回的 JSON 粘回②，点「**填入页面**」，各页自动填好。
3. 也可以直接点「**+ 封面 / + 双语分析 / + 排名表格 / + 列表 / + 政策 / + 文本**」手动加页、改字。
4. 「品牌设置」里可改**栏目名**（小绿书报头用，如 签证信息 / 院校信息）和**页脚备注**。
5. 右侧实时预览。导出：每页右下角「下载」单张下；顶部「**下载全部**」逐张下。

> 内容、平台、栏目名、页脚会自动存在浏览器本地，刷新不丢。

## 两套品牌主题

- **小红书**：深藏蓝单色（封面色 `#191970`），报头 logo + 斜杠条 + LIGHT UP THE FUTURE!，内容区藏蓝圆角框。
- **小绿书**：红色 logo + 蓝色边框/标题（封面色 `#1e66cc`）+ 红色小标题，报头 logo + 栏目名。

在 `themes.css` 里用 CSS 变量定义，切换 `<html data-platform>` 即整体换肤。

## 页面类型

| 类型 | 用途 | 字段 |
|---|---|---|
| 封面 cover | 报头 + 方块大标题（+小红书 3D 人物） | 大标题、是否显示人物 |
| 双语分析 bilingual | 拒签原因那种 | 小标题、英文加粗段、中文翻译、行动小标题、步骤 |
| 排名表格 table | 录取数据 / QS 排名 | 标题、列标题、表格行 |
| 列表 list | 项目一览 | 小标题、若干「项目名 + 一句话」 |
| 政策 policy | 政策更新要点 | 标题、要点清单 |
| 文本 text | 自由图文 | 标题、正文 |

## 要放进 assets/ 的素材（放了就自动生效）

| 文件 | 用途 | 说明 |
|---|---|---|
| `assets/logo-mark.png` 或 `.svg` | EduLight logo | 透明底单色，会按主题自动上色（小红书藏蓝 / 小绿书红） |
| `assets/memoji.png` | 小红书封面 3D 人物 | 透明底 |
| `assets/fonts/display.ttf` 或 `.woff2` | 封面方块大字体 | 缺省回退系统粗黑体 |

> 没放这些文件也能正常用：logo 用文字占位，封面字体用系统粗黑体，人物不显示。

## 技术说明

- 纯静态：HTML + CSS + JS，无框架、无构建、无后端、无密钥。
- 导出零依赖：用浏览器原生 `SVG <foreignObject>` + `canvas` 把卡片转 PNG（1080×1440），离线可用。
- 封面字体导出时以 base64 内联进 SVG，保证导出 PNG 与预览一致。
- logo 用 CSS mask 按主题色重新上色，一个文件适配两套主题。
- AI 整理走 `claude://` 深链接（不调用付费 API）。

## 部署（Vercel）

把本仓库连到 Vercel，无需任何环境变量，push 即自动部署。
本地预览：仓库目录里跑 `python3 -m http.server 8000`，浏览器开 `http://localhost:8000`。
